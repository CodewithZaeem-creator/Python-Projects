# 🎮 Tic-Tac-Toe

A classic command-line Tic-Tac-Toe game built with Python. Play as **X** against a computer opponent playing **O**.

## ✨ Features

- Human vs computer gameplay
- Input validation
- Win and draw detection
- Computer can win when possible and block your winning move
- Center and corner move strategy
- Option to play multiple rounds
- Uses only Python's standard library

## ▶️ How to Run

Make sure Python 3.9+ is installed, then run:

```bash
python tic_tac_toe.py
```

## 🧠 Concepts Practiced

- Functions
- Lists
- Loops
- Conditional statements
- Input validation
- Random choices
- Game logic
- Basic computer decision-making

## 📌 Controls

Choose a position by entering a number from **1 to 9**:

```text
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
```

You play as **X** and the computer plays as **O**.
