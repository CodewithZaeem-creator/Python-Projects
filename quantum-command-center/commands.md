# Quantum Core Commands

| Command | Purpose |
|---|---|
| `help` | Show available commands |
| `status` | Show core status |
| `diagnostics` | Inspect basic system information |
| `time` | Show temporal sync |
| `calc 12 * 8` | Safely evaluate arithmetic |
| `mission` | Generate a coding mission |
| `remember name Zaeem` | Store session memory |
| `recall name` | Retrieve memory |
| `memory` | Show stored memories |
| `exit` | Shut down |
