# ⚛️ Quantum Command Center

A deliberately over-engineered Python CLI playground that combines a futuristic command-center theme with useful programming concepts.

## Modules

- Core status monitor
- System diagnostics
- Temporal clock
- Safe arithmetic evaluator using `ast`
- Session memory bank
- Random coding mission generator

## Run

```bash
python main.py
```

This is a learning project: the "quantum" theme is fictional and the program does not perform real quantum computing.
